Projects

Milk Yield Tracker API

C# · .NET 10 · EF Core · SQL Server · xUnit

A rebuild of the Excel milk tracker I made on the farm in 2024. It flags a cow when her day total is more than 15% below her own average of the previous 7 complete days, so a sick or stressed cow is spotted early.

25 automated tests cover the rule and the API end to end. The herd in the demo is made up.

Code on GitHub

Feed vs Grass Balance Calculator

TypeScript · Vite · Vitest · GitHub Pages

Enter cows, hectares, intake and grass growth, and it shows week by week whether pasture covers what the herd eats, and when you're heading for a feed shortfall.

The weekly maths is in one tested file (16 tests). Example numbers are made up, and it is not farm advice.

Live demo Code on GitHub

How these were built: I chose the problems and the rules (the 15% and 7-day thresholds, SQL Server). AI wrote most of the code and tests. I went through the core rule in each project, broke it on purpose to see which test failed, and wrote a boundary test myself. Both READMEs say this too.
