Milk Yield Tracker

C#, .NET 10, EF Core, SQL Server, xUnit

Code on GitHub

A rebuild of the Excel milk tracker I made on the farm in 2024. A cow is flagged when her day total falls more than 15% below her own average of the previous seven complete days, so a sick or stressed cow gets noticed the same day.

An API with 25 automated tests covering the rule and the full request cycle. The herd in the demo is made up.

Feed vs Grass Balance Calculator

TypeScript, Vite, Vitest, GitHub Pages

Live demoCode on GitHub

Enter cows, hectares, intake and grass growth, and it shows week by week whether the pasture covers what the herd eats, and when you're heading for a feed shortfall.

The weekly maths lives in one file with 16 tests. The example numbers are made up, and it isn't farm advice.

How they were built: I chose the problems and the rules, including the 15% and seven-day thresholds and SQL Server. AI wrote most of the code and tests. In each project I read through the core rule, broke it on purpose to see which test failed, and wrote a boundary test myself. Both READMEs say the same.
